# 검증 범위

- Node: 15분 전 추천, 주말, 누락된 회차, 자정 마감, 이전 기록 독립 복사, 전체/부분 강조, 반출, 구역 유효성, 최대 3개 코드, 백업 검증, 텍스트 출력.
- Playwright: 모바일 크기로 작성 → 재실행 → 저장 → 다음 점검 → 상태 변경 → 컨테이너 교체 → 반출, 구역 설정, 이력, 백업 복원, 320px 가로 넘침 확인.
- Android: Gradle APK 조립 및 lint. CI 결과는 GitHub Actions에서 확인.

실제 Android에서 추가 확인: 한글/영문 키보드, 하단 버튼과 키보드 겹침, 잠금·앱 전환·회전 후 작성 유지, 오프라인 저장·재실행, 시스템 클립보드와 파일 선택기, 업데이트 전 백업과 복원.

브라우저 테스트를 실제 사용자 휴대전화 검증으로 표현하지 않습니다. 테스트 예시는 DEMO-* 가상 값만 사용합니다. 사진 및 동기화는 미구현 범위입니다.
