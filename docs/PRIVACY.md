# 데이터 원칙

비공개 저장소에도 실제 컨테이너 번호, 아이템 코드, shipment 번호, 업무 기록, WMS 자료, 사진을 넣지 않습니다. 테스트·스크린샷·문서·PR·릴리스에는 DEMO-* 가상 값만 사용합니다. 첫 실행에는 미리 채운 업무 데이터가 없습니다.

인터넷, 카메라, 위치, 공유 저장소 전체 접근 권한이 없습니다. 서버와 분석 SDK가 없고 Android 자동 클라우드 백업도 비활성화합니다. 앱 내부 JSON 저장은 별도 앱 암호화를 구현하지 않으며 기기 잠금과 Android 앱 격리에 의존합니다. 이 배포는 개발용 debug 미리보기입니다.

복사·파일 내보내기는 사용자 요청으로만 수행합니다. 클립보드 및 백업에는 입력한 업무 정보가 포함됩니다. 시스템 파일 선택기에서 클라우드 위치를 고르면 그 위치에 저장될 수 있으므로 적절한 저장 위치를 선택하세요.

GitHub는 코드와 APK 배포에만 사용하며 기기의 실제 점검 기록을 동기화하지 않습니다. 이 구현이 과거 공개 이력의 삭제 여부까지 보장하지는 않습니다.
