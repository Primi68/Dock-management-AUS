Ready to drop인 Dock에서도 상태를 먼저 바꾸지 않고 바로 기록할 수 있습니다. 컨테이너 번호 또는 아이템 코드를 입력하면 Full로 자동 전환됩니다.

- 모든 Dock 1~20에서 번호 없이 아이템 코드를 먼저 입력할 수 있습니다.
- 입력과 Full 전환은 한 번의 되돌리기로 함께 취소할 수 있습니다. 재실행 및 JSON 백업·복원 후에도 유지됩니다.
- Empty / In process 등 직접 지정한 상태는 유지합니다. 공백·메모만 입력해도 바뀌지 않습니다.
- 번호나 코드를 지워도 자동 반출로 처리하지 않습니다. 번호를 나중에 적어도 기존 코드가 유지됩니다.
- 메뉴에 이전 버전으로 고정 표시되던 문구를 0.3.5로 바로잡았습니다.

0.3.4와 동일한 고정 키로 서명하며, 0.3.4 위에 앱을 삭제하지 않고 업데이트할 수 있습니다. 0.3.3 이하의 임시 서명 APK에서 이동할 때는 검증한 JSON 백업을 먼저 확보해야 합니다.

업무 규칙·모바일 브라우저 테스트, Android release 빌드/lint, API 35 에뮬레이터의 네이티브 저장·재실행 및 서명·덮어 설치 후 기록 보존 검사를 모두 통과해야 게시됩니다. 실제 사용자 휴대전화의 키보드 및 시스템 파일 선택기 검증과는 구분합니다.

English: Entering a container number or item code on a Ready to drop dock now defaults its status to Full. Undo reverses both the entry and the automatic status change together. Existing manual statuses and previous checks are preserved. Uses the same fixed signing key as 0.3.4.
