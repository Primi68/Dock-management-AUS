개인용 오프라인 Android MVP. 이번 버전부터 고정된 서명 키로 만든 배포용 APK를 제공합니다.

### 변경 내용

- 매번 새로 생성되던 개발용 서명을 고정된 배포용 서명으로 전환했습니다.
- 이후 같은 키로 서명한 새 버전은 앱을 삭제하지 않고 기존 기록을 유지하며 업데이트할 수 있습니다.
- 키가 없거나 서명이 기준과 다르면 배포를 중단합니다. 임시 키로 대체하지 않습니다.
- 0.3.3의 모든 Dock 번호 변경 시 코드·상태·메모 보존과 내용 초기화 기능을 포함합니다.

### 최초 전환 시 설치

0.3.3 이하의 기존 GitHub APK와는 서명이 다릅니다. 기존 앱에서 JSON 전체 백업을 앱 밖에 저장하고 확인한 뒤, 한 번만 기존 앱 삭제 → 0.3.4 설치 → JSON 복원을 진행하세요. 백업 전에 앱을 삭제하면 기록이 사라집니다. 이후 고정 서명 버전의 업데이트에서는 앱을 삭제하지 마세요.

Android 8 이상, 오프라인 개인용 미리보기입니다. APK 해시는 SHA256SUMS.txt, 고정 서명 인증서 지문은 SIGNING-CERT-SHA256.txt에 있습니다. 키와 비밀번호는 배포 파일에 포함하지 않습니다.

English: This preview starts a fixed release-signing identity. Back up and restore once when moving from older debug-signed previews. Future releases signed with this same key can update in place without uninstalling.

업무 규칙·모바일 화면 테스트, release 빌드/lint·Android 에뮬레이터 및 서로 다른 CI 실행기에서 만든 APK의 덮어 설치 후 기록 보존 검사가 모두 성공해야 게시됩니다. 실제 사용자 휴대전화 검증과는 구분합니다.
