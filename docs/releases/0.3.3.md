개인용 오프라인 Android MVP. 컨테이너 번호를 나중에 확인해 입력할 때 먼저 적은 아이템 코드가 지워지던 동작을 개선했습니다.

### 변경 내용

- Wheel을 포함한 Dock 1~20 전체에서 번호를 입력·변경해도 코드·내용물·상태·메모를 유지합니다.
- 실제로 번호가 달라지면 기존처럼 새 컨테이너로 강조합니다. 오타 수정은 번호만 정정을 선택하며 현재 입력값을 바꾸지 않습니다.
- 내용 초기화는 별도 버튼과 확인 창으로 실행합니다. 번호는 유지하고 나머지 내용을 비우며, 되돌리기·다시 실행을 지원합니다.
- 재실행·JSON 백업 복원 시 작성 중 내용과 되돌리기 이력을 유지합니다.

English: Enter item codes first and confirm the container number later. Changing the number now keeps your observations on every Dock. Use Correct number only for a typo, or Clear contents to reset the other fields after confirmation.

### 설치

설치 전 기존 앱에서 JSON 전체 백업을 저장하세요. Android 8 이상, 미리보기용 debug APK입니다. 기존 미리보기와 서명이 다르면 덮어 설치할 수 없으므로, 먼저 백업을 확보한 뒤 재설치·복원해야 합니다. 실제 운영 데이터는 포함하지 않습니다. 설치 및 제한 사항은 저장소 [설치 안내](https://github.com/Primi68/Dock-management-AUS/blob/main/docs/INSTALL.md)를 확인해 주세요.

업무 규칙·모바일 화면 테스트, Android 빌드/lint와 에뮬레이터 검증이 모두 성공해야 릴리스가 게시됩니다. 실제 사용자 휴대전화 테스트와는 구분합니다.
