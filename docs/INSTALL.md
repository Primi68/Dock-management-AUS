# 설치와 백업

저장소 접근 권한이 있는 계정으로 GitHub에 로그인하고 Releases의 `Dock-Notes-0.1.0-preview.apk`를 Android에 받습니다. 파일을 열고 요청되는 경우 해당 브라우저/파일 앱의 `알 수 없는 앱 설치`를 허용합니다. **Android 8 이상**에서 Dock Notes를 실행합니다. private 저장소 링크는 로그인 없이 접근할 수 없습니다. 함께 제공된 SHA256SUMS.txt로 파일 해시를 검증할 수 있습니다.

다음 점검 → 날짜·점검 시간 확인 → 최근 기록 불러오기 → 변경 내용 수정 → 저장 · 점검 보기. 컨테이너가 바뀌면 번호를 눌러 새 컨테이너로 변경합니다. 단순 오타는 같은 컨테이너·번호 정정, 반출은 Ready to drop을 사용합니다.

메뉴의 전체 기록 백업(JSON)을 사용하세요. 텍스트는 읽기용이고 복원에는 JSON이 필요합니다. 복원은 기기의 현재 기록 전체를 대체하므로 먼저 현 데이터를 백업하세요.

미리보기는 개발용 서명 APK입니다. 서로 다른 서명으로 빌드한 APK는 덮어 설치할 수 없습니다. 설치 실패 시 무작정 앱을 삭제하지 말고 기존 앱에서 JSON 백업부터 내보내세요. 서명 변경으로 재설치가 필요하면 설치 후 백업을 복원합니다. 앱 삭제 시 내부 기록은 지워집니다.

사진·공동 사용·엑셀/WMS 자동 연동은 이 버전에 없습니다. 실제 휴대전화와 업무 환경에서 사용하며 피드백으로 개선합니다.
