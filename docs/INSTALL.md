# 설치와 백업

저장소 접근 권한이 있는 계정으로 GitHub에 로그인하고 Releases의 `Dock-Notes-0.3.3-preview.apk`를 Android에 받습니다. 파일을 열고 요청되는 경우 해당 브라우저/파일 앱의 `알 수 없는 앱 설치`를 허용합니다. **Android 8 이상**에서 Dock Notes를 실행합니다. private 저장소 링크는 로그인 없이 접근할 수 없습니다. 함께 제공된 SHA256SUMS.txt로 파일 해시를 검증할 수 있습니다.

다음 점검을 한 번 누르면 최근 기록이 즉시 불러와집니다. 변경 내용 수정 → 저장 · 점검 보기로 사용합니다. 날짜·점검 시간은 자동 지정되며 필요한 경우에만 수정합니다. 컨테이너 번호는 바로 타이핑합니다. 코드를 먼저 적고 번호를 나중에 바꿔도 코드·내용물·상태·메모는 유지됩니다. 오타 수정은 번호만 정정을 선택하고, 비우고 다시 적을 때만 내용 초기화를 눌러 확인합니다. 반출은 기존처럼 Ready to drop을 선택해 확인합니다.

메뉴의 전체 기록 백업(JSON)을 사용하세요. 텍스트는 읽기용이고 복원에는 JSON이 필요합니다. 복원은 기기의 현재 기록 전체를 대체하므로 먼저 현 데이터를 백업하세요.

미리보기는 개발용 서명 APK입니다. 서로 다른 서명으로 빌드한 APK는 덮어 설치할 수 없습니다. 설치 실패 시 무작정 앱을 삭제하지 말고 기존 앱에서 JSON 백업부터 내보내세요. 서명 변경으로 재설치가 필요하면 설치 후 백업을 복원합니다. 앱 삭제 시 내부 기록은 지워집니다.

사진·공동 사용·엑셀/WMS 자동 연동은 이 버전에 없습니다. 실제 휴대전화와 업무 환경에서 사용하며 피드백으로 개선합니다.

## 0.2 변경

결과는 가로 한 줄이며 1~8 / 9~13 / 14~20 버튼으로 범위를 볼 수 있습니다. 상단 점검 선택에서 이전 시간도 수정할 수 있습니다. 작성 중인 다음 점검 취소와 최신 저장 점검 삭제는 확인 후 실행합니다. 과거 기록 수정은 이후 점검의 관찰 내용을 덮어쓰지 않습니다.

## 되돌리기

작성 화면 하단의 ↶ 되돌리기로 마지막 수정을 복구하고 ↷로 다시 실행합니다. Ready to drop으로 비운 내용도 번호·코드·상태·메모를 한 번에 되돌립니다. 입력칸에서 이어 적은 글자는 한 단계로 묶습니다. 최대 50단계이며 임시 작성 중에는 재실행해도 유지됩니다. 저장하면 편집 내역은 초기화됩니다.


## 0.3 언어 설정

메뉴(☰) → 설정 → 언어 설정 → 언어 / Language에서 English를 선택하고 설정 저장을 누릅니다. 즉시 영어로 전환되며 앱을 다시 열어도 유지됩니다. 한국어로 돌아오려면 Settings → Language settings → Language / 언어 → 한국어 → Save settings를 누릅니다. 취소하면 현재 언어를 유지합니다.

버튼, 항목 이름, 확인 창, 오류 안내, 복사·텍스트 내보내기의 변경 표시가 선택한 언어를 사용합니다. 직접 적은 컨테이너 번호·코드·내용물·메모와 구역 제목은 자동 번역하지 않습니다. 따라서 기존에 한국어로 저장한 구역 이름은 영어 화면에서도 그대로 보이며 설정에서 직접 바꿀 수 있습니다. 상태 값은 기존처럼 Full / In process / Empty / Ready to drop을 사용합니다. Android 시스템 파일 선택기의 언어는 휴대전화 설정을 따릅니다.

언어 설정은 JSON 전체 백업에 포함됩니다. 복원하면 백업의 언어 설정도 적용됩니다. 언어 설정이 없는 구버전 백업은 한국어로 열립니다. 기존 점검·비교 기준·작성 중 되돌리기 이력은 언어 변경으로 바뀌지 않습니다.

English: Open ☰ → Settings → Language settings, choose English and tap Save settings. Your entered records and group names stay unchanged. Before replacing an older preview APK, export a full JSON backup. If Android rejects the update because the signing certificate differs, uninstall only after saving that backup, install the new APK, and restore it from the menu.


## 0.3.1 설정 메뉴 정리

메뉴에는 설정이 표시됩니다. 설정 첫 화면에서 언어 설정과 점검 시간 · 구역 설정을 별도로 선택합니다. 언어 화면에는 언어 선택만, 점검 설정에는 시간·근무 요일·구역만 표시합니다. 취소하거나 Android 뒤로 가기에서 취소를 확인하면 설정 첫 화면으로 돌아가며, 점검으로 돌아가기 버튼으로 작성 또는 조회 중이던 점검을 다시 볼 수 있습니다.


## 0.3.2 맨 아래 이동

점검 작성·수정 화면에서 날짜/점검 시간 수정·취소·임시 저장 안내 아래, 첫 구역 제목 위의 중앙 ↓ 버튼을 누르면 맨 아래 Dock 20으로 즉시 이동합니다. 순서는 계속 1~20이고 기록 내용은 바뀌지 않습니다. 조회 화면에는 이 버튼이 없습니다. 영어 접근성 이름은 Go to bottom입니다.

## 0.3.3 번호를 나중에 입력하기

Wheel을 포함한 모든 Dock에서 내부 확인 중 아이템 코드를 먼저 기록한 뒤 외부에서 컨테이너 번호를 확인해 입력하세요. 이전 점검의 번호를 다른 번호로 바꿔도 현재 적은 내용이 유지됩니다. 다만 이전 점검에서 그대로 가져온 코드·상태도 유지되므로 실제 관찰한 값에 맞게 수정하세요.

번호가 다르면 새 컨테이너 강조는 계속 표시합니다. 오타만 고친 경우 번호만 정정(Correct number only)을 선택하고, 실제 교체라면 새 컨테이너로 표시(Mark as new container)로 되돌릴 수 있습니다. 다른 입력 내용을 다시 쓰고 싶을 때는 내용 초기화(Clear contents)를 선택하세요. 확인 후에도 컨테이너 번호는 남으며, ↶ 되돌리기로 비운 내용을 복구할 수 있습니다.
