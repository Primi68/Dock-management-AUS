# 설치와 백업

저장소 접근 권한이 있는 계정으로 GitHub에 로그인하고 Releases의 `Dock-Notes-0.2.0-preview.apk`를 Android에 받습니다. 파일을 열고 요청되는 경우 해당 브라우저/파일 앱의 `알 수 없는 앱 설치`를 허용합니다. **Android 8 이상**에서 Dock Notes를 실행합니다. private 저장소 링크는 로그인 없이 접근할 수 없습니다. 함께 제공된 SHA256SUMS.txt로 파일 해시를 검증할 수 있습니다.

다음 점검을 한 번 누르면 최근 기록이 즉시 불러와집니다. 변경 내용 수정 → 저장 · 점검 보기로 사용합니다. 날짜·점검 시간은 자동 지정되며 필요한 경우에만 수정합니다. 컨테이너 번호는 바로 타이핑합니다. 변경 후 다른 칸으로 이동하면 이전 내용이 비워집니다. 오타 수정은 번호 아래의 이전 내용 되살리기를 사용하고 반출은 Ready to drop을 선택해 확인합니다.

메뉴의 전체 기록 백업(JSON)을 사용하세요. 텍스트는 읽기용이고 복원에는 JSON이 필요합니다. 복원은 기기의 현재 기록 전체를 대체하므로 먼저 현 데이터를 백업하세요.

미리보기는 개발용 서명 APK입니다. 서로 다른 서명으로 빌드한 APK는 덮어 설치할 수 없습니다. 설치 실패 시 무작정 앱을 삭제하지 말고 기존 앱에서 JSON 백업부터 내보내세요. 서명 변경으로 재설치가 필요하면 설치 후 백업을 복원합니다. 앱 삭제 시 내부 기록은 지워집니다.

사진·공동 사용·엑셀/WMS 자동 연동은 이 버전에 없습니다. 실제 휴대전화와 업무 환경에서 사용하며 피드백으로 개선합니다.

## 0.2 변경

결과는 가로 한 줄이며 1~8 / 9~13 / 14~20 버튼으로 범위를 볼 수 있습니다. 상단 점검 선택에서 이전 시간도 수정할 수 있습니다. 작성 중인 다음 점검 취소와 최신 저장 점검 삭제는 확인 후 실행합니다. 과거 기록 수정은 이후 점검의 관찰 내용을 덮어쓰지 않습니다.
